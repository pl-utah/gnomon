#+title: Euclid I.1 implementation reference

* Scope

Paper: Avigad, Dean & Mumma, [[https://arxiv.org/html/0810.4315v3][A formal system for Euclid's Elements]]. This is
the paper's main I.1 proof in §4.2, with the requested final =c ≠ a,b= checks;
it excludes other nondegeneracy auxiliaries and all of \(E\). [X] means
implemented in this checkout; [ ] means absent. A
represented fact is not automatically an implemented inference.

* Implemented inference rules

Call =engine.infer_facts()= to repeatedly apply these rules in place until no
new facts are added — [[file:src/infer.rs::6][src/infer.rs]]. It mutates =engine.facts=; it does not
enumerate =known_objects=. Rules below cite their paper sections and rule numbers.

** Diagrammatic inferences (§3.4)
- [X] Center is inside its circle (circle axiom 3):
  #+begin_example
  CenterOfCircle(a, α)  ⇒  InsideCircle(a, α)
  #+end_example
  [[file:src/infer.rs::15][src/infer.rs]]
- [X] Circles intersect (intersection rule 5):
  #+begin_example
  OnCircle(a, α)   InsideCircle(a, β)
  OnCircle(b, β)   InsideCircle(b, α)
  ───────────────────────────────────
  CirclesIntersect(α, β)
  #+end_example
  [[file:src/infer.rs::61][src/infer.rs]]. In I.1, each circle's center lies on the
  other circle and is inside its own circle, so these premises follow from
  the construction facts plus the center-inside rule. The result says the
  circles intersect; it does not select an intersection point.
- [ ] Center uniqueness (circle axiom 2):
  #+begin_example
  CenterOfCircle(a, α)   CenterOfCircle(b, α)  ⇒  a = b
  #+end_example
- [X] Inside-point / boundary-point distinctness, derived by unit propagation
  from E §3.4 circle axiom 4:
  #+begin_example
  InsideCircle(P, γ)   OnCircle(Q, γ)
  ───────────────────────────────────
  DistinctPoints(P, Q)
  #+end_example
  [[file:src/infer.rs::27][src/infer.rs]]. This is the optimized consequence of
  =InsideCircle(P,γ) ⇒ ¬OnCircle(P,γ)= plus equality propagation; it is not a
  new geometric axiom. Both points must concern the same circle; unrelated
  circles and fresh IDs alone do not imply distinctness.

* Euclid I.1: construction and proof support (§§3.3, 4.2)

Main proof outline in pseudomath:

#+begin_example
Given a ≠ b
Construct α centered at a through b; construct β centered at b through a
Infer CirclesIntersect(α, β)
Choose c on α ∩ β
Transfer radii: Length(a,b) = Length(a,c)
                Length(b,a) = Length(b,c)
Use segment symmetry and equality transitivity:
                Length(a,b) = Length(b,c) = Length(c,a)
#+end_example
