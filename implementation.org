of \(E\). [X] means implemented in this checkout; [ ] means absent. A
represented fact is not automatically an implemented inference.

* Implemented inference rules

Call =engine.infer_facts()= to repeatedly apply these rules in place until no
new facts are added — [[file:src/infer.rs::6][src/infer.rs]]. It mutates =engine.facts=; it does not
enumerate =known_objects=. Rules below cite their paper sections and rule numbers.

** Diagrammatic inferences (§3.4)
- [X] Center is inside its circle (circle axiom 3):
  #+begin_example
  CenterOfCircle(a, α)  ⇒  InsideCircle(a, α)
  #+end_example
  [[file:src/infer.rs::15][src/infer.rs]]
- [X] Circles intersect (intersection rule 5):
  #+begin_example
  OnCircle(a, α)   InsideCircle(a, β)
  OnCircle(b, β)   InsideCircle(b, α)
  ───────────────────────────────────
  CirclesIntersect(α, β)
  #+end_example
  [[file:src/infer.rs::61][src/infer.rs]]. In I.1, each circle's center lies on the
  other circle and is inside its own circle, so these premises follow from
  the construction facts plus the center-inside rule. The result says the
  circles intersect; it does not select an intersection point.
- [ ] Center uniqueness (circle axiom 2):
  #+begin_example
  CenterOfCircle(a, α)   CenterOfCircle(b, α)  ⇒  a = b
  #+end_example
- [ ] Inside excludes on-circle (circle axiom 4):
  #+begin_example
  InsideCircle(a, α)  ⇒  not OnCircle(a, α)
  #+end_example

** Metric inferences (§3.5)
- [X] Equality transitivity, any shared side (all four positions):
  #+begin_example
  EqualLengths(x,y)   EqualLengths(x,z)  ⇒  EqualLengths(y,z)
  EqualLengths(x,y)   EqualLengths(z,x)  ⇒  EqualLengths(y,z)
  EqualLengths(y,x)   EqualLengths(x,z)  ⇒  EqualLengths(y,z)
  EqualLengths(y,x)   EqualLengths(z,x)  ⇒  EqualLengths(y,z)
  #+end_example
  Implemented at [[file:src/infer.rs::39][src/infer.rs]]. Equality-side normalization also
  lets these facts be queried in either order.
- [ ] Length is zero iff its endpoints are equal (metric rule 1, §3.5).
- [ ] Length nonnegativity (metric rule 2, §3.5).

** Diagram-segment transfers (§3.6)
- [X] Equal radii (rule 3, forward direction):
  #+begin_example
  CenterOfCircle(a, α)   OnCircle(b, α)   OnCircle(c, α)
  ──────────────────────────────────────────────────────
  EqualLengths(Length(a,b), Length(a,c))
  #+end_example
  Implemented at [[file:src/infer.rs::25][src/infer.rs]]. This is an inference rule, not merely
  storage of =EqualLengths=.
- [ ] Rule 1, segment addition:
  #+begin_example
  Between(a,b,c)  ⇒  Length(a,b) + Length(b,c) = Length(a,c)
  #+end_example
- [ ] Rule 2, circle identity from common center and radius.
- [ ] Rule 3, converse direction: radius equality implies circle incidence.
- [ ] Rule 4, radius inequality characterizes inside-circle points.

* Euclid I.1: construction and proof support (§§3.3, 4.2)

Main proof outline in pseudomath:

#+begin_example
Given a ≠ b
Construct α centered at a through b; construct β centered at b through a
Infer CirclesIntersect(α, β)
Choose c on α ∩ β
Transfer radii: Length(a,b) = Length(a,c)
                Length(b,a) = Length(b,c)
Use segment symmetry and equality transitivity:
                Length(a,b) = Length(b,c) = Length(c,a)
#+end_example

- [X] Record the input hypothesis =a ≠ b= separately from inferred facts —
  =Context::assume_distinct_points= resolves the names, while =Engine= records
  it in =assumptions= and the engine fact set for construction checks —
  [[file:src/context.rs::35][src/context.rs]], [[file:src/engine.rs::40][src/engine.rs]].
- [X] Construct a circle centered at one point through another (construction
  rule 2, §3.3) after both points are registered and =DistinctPoints= is known —
  [[file:src/engine.rs::57][src/engine.rs]]. It adds the center/on-circle facts and saturates inference.
- [X] Infer the two constructed circles intersect, from their center/on-circle
  facts (diagram intersection rule 5, §3.4; see rule above).
- [X] Choose/create =c= as a fresh point on both circles after
  =CirclesIntersect= is known (intersection construction rule 6, §3.3) —
  [[file:src/engine.rs::79][src/engine.rs]]. The fresh ID is a new symbol, not a proof of geometric
  distinctness from any existing point.
- [X] Given the center/on-circle facts for =c=, infer the two radius
  equalities, then use equality transitivity to relate them — rules above.
  The sequential API is tested; script syntax is documented separately.
- [X] Check the final equilateral-triangle goal by querying the two target
  =EqualLengths= facts; the sequential API test verifies them —
  [[file:src/context.rs::133][src/context.rs]].
- [ ] Prove the auxiliary claims =c ≠ a= and =c ≠ b=; these are discussed
  after the main proof in §4.2 and are outside this inventory's scope.
